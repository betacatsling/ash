# 工作区目录建议与静默刷新

2026-09-06。

## 正常刷新不再显示“正在恢复工作区”

连接服务每次轮询都读取工作区和会话快照，这属于正常同步。此前它每三秒发布一次恢复进度，导致侧栏插入再移除状态文字。本次在 AppStore 中区分首次/手动/失败重连与健康后台轮询，过滤普通轮询的检查、恢复和就绪进度；真实安装阶段、连接错误和更新失败提示仍保留。主机详情在健康轮询期间保留最近连接时间，不切换成临时状态文字。

回归检查订阅实际 `runtimeSetup` 发布流，确认健康刷新不会发布恢复提示，手动重连仍显示进度。

## 添加工作区时选择实际目录

路径框下方列出所选主机上的真实目录。空输入从该主机的主目录开始，支持绝对路径和 `~/`，输入部分目录名会筛选匹配结果。点击目录继续向下浏览，上箭头返回上一级；“使用此目录”确认并收起列表。上下键选择建议，Return 或 Tab 进入选中目录。

名称随选中的目录自动填写，用户手动填写过的名称会保留。本地仍保留原生“选择…”按钮。切换主机会重置路径，旧请求的结果不能覆盖新主机或新输入的目录列表。只有确认目录存在后才能添加，保存使用执行端返回的绝对物理路径。

目录读取使用同一份只读 POSIX shell 操作，本地通过 `/bin/sh`，远端通过已有 OpenSSH 配置执行。不依赖新运行协议、远端 Python 或运行程序更新，直接 SSH 主机也可使用。参数经独立引用，不执行输入中的 shell 表达式；返回数据以 NUL 分隔，兼容空格、中文、引号和换行目录名。普通文件不显示，隐藏目录需输入以 `.` 开头的名称。一次最多返回 200 个匹配目录，输入有 220 ms 防抖。
