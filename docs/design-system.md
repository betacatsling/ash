# Ash 界面设计规范

2026-09-07 · 原生 macOS 工作台

## 方向

保留终端工作台的紧凑结构，用柔和中性色、明确的文字层次和少量铜色建立秩序。终端内容是视觉中心。主导航用灰阶底色区分选中项，铜色仅强调品牌、当前标签与关键操作。

比较过编辑式大留白、紧凑工具布局和柔和极简三个方向；采用后两者的结合。欢迎页可以留白，工作中的标签、目录和工具面板保持紧凑。继续使用系统字体及 SF Symbols，避免额外字体资源、背景插画和装饰动效。

## 共享色彩

所有界面色彩集中在 `Sources/Ash/Appearance.swift`，通过原生动态颜色适配明暗外观。

正文继续使用系统 primary / secondary 语义色。分隔线为正文色的 9% 不透明度，悬停为 4.5%。警告和错误保留系统语义色。终端背景、ANSI 调色板和终端字体设置保持原有行为。

## 排版与尺寸

- 标题：SF 系统字体，欢迎页 30 pt medium，弹窗标题 22 pt medium。
- 正文与导航：12–13 pt，标题使用 medium，辅助信息使用系统 secondary。
- 路径及快捷键：SF Mono，10–11 pt。运行计数使用等宽数字。
- 工具栏统一 40 pt，底部信息栏统一 28 pt。
- 主要布局间距使用 8 / 12 / 16 / 24 / 32 pt；弹窗外边距 24–28 pt。
- 列表、搜索框与标签圆角 8 pt；快捷键标记 4 pt；弹窗标题图标容器 12 pt。
- 鼠标操作的桌面工具保持紧凑，不将触屏尺寸标准强加于密集的终端标签；保留原生按钮、快捷键和辅助功能标签。

## 已应用范围

侧栏、终端标签栏、右侧面板标签栏、状态栏、首次打开页、工作区欢迎页、任务创建、设置、主机管理与编辑、工作区创建与重命名、终端重命名、环境准备与认证、文件树、Git 差异、任务清单及会话信息。

交互细节：搜索可清除；列表与工具按钮提供悬停反馈；禁用工具按钮降低不透明度；选中 Agent 显示勾选标记。工作区宽度不足时，欢迎页按钮及快捷键纵向排列；高度不足时滚动显示。未取得主机检测结果时显示“等待检测”。未选择工作区时禁用标签栏的新建终端按钮。

表单继续使用原生 macOS 控件。终端视图不加入装饰留白和尺寸动画，避免影响终端排版、焦点及分屏行为。
