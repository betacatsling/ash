# 主机管理与添加流程

2026-09-06。采用简洁列表和按需展开设置，延续 Ash 的系统字体、语义明暗颜色和暖色强调。

## 使用方式

- 主机窗口保留在 620 × 560 pt。按名称或地址搜索，点击主机展开连接状态、运行版本、关联工作区及操作。展开后自动滚动到所选主机，错误详情可以继续展开。
- “添加主机”打开独立表单。SSH 地址或别名必填，显示名称可选；名称留空时使用地址。可以从现有 SSH 配置选择静态别名。
- 支持托管主机和直接 SSH。托管模式可以自动安装运行环境；自定义运行程序路径按需展开。SSH 端口、密钥和跳板继续由 OpenSSH 配置管理。
- **添加**仅保存，不触发后台连接；**添加并连接**保存后立即检查连接。仅保存的主机在之后主动检查连接时进入自动连接流程，也可在编辑中调整“自动连接此主机”。旧配置缺少此字段时保留原来的自动连接行为。
- 编辑保留主机 ID。存在关联工作区（包括隐藏工作区）时，不能把地址改指向另一台服务器，也不能移除主机；重命名不影响原工作区和会话。
- “检查连接”尊重暂停自动安装的设置。“安装 / 更新”执行一次明确的手动操作，但不会开启已暂停的自动更新。直接 SSH 的连接检查不会安装运行程序。
- 认证终端关闭时清理对应的显示连接，再检查当前保存的主机配置。每次认证使用独立视图 ID，避免重复打开时复用已经结束的终端。

## 后台实现

`HostConfiguration.swift` 管理表单模型、地址和路径校验、错误分类及退避策略。地址会去除首尾空白，拒绝空用户、重复 `@`、选项、命令片段和误填的 `host:port`；保留 IPv6 支持。相同 SSH 地址不能重复登记。

`AppStore+Hosts.swift` 集中管理新增、编辑、移除、连接和刷新。配置只有成功写盘后才算保存，失败时恢复内存中的原主机列表。每台主机独立处理连接任务，重复请求合并；离线失败按 3–60 秒退避，手动检查立即重试。慢主机不会阻止其他主机继续刷新，过期连接结果和进度不能覆盖已变更的配置。

`HostConnectionService.swift` 管理直接 SSH 检查、托管运行环境准备、健康检查和工作区快照。远端自动更新失败时继续使用健康且协议兼容的已有运行环境。远端安装仍沿用原有校验、原子激活和回退机制。

`SSHConfigDiscovery.swift` 读取静态 `Host` 与 `Include`，支持引号、注释、等号和包含文件通配符，并限制递归、文件数量与读取大小。它不执行 `Match exec`，不尝试代替 OpenSSH 解释条件配置。
