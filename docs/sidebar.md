# 右边栏工作面板

右边栏顶部的「+」可以打开任务清单、会话信息、文件、端口或网页，以及 Git Diff。标签可切换和关闭，拖动终端与右边栏之间的分隔线调整宽度。⌘⌥I 收起或展开右边栏。

## 任务清单

- 由用户手动添加、编辑、勾选任务。只支持任务和子任务两层；行尾菜单可添加子任务、调整顺序和删除。
- 勾选父任务会同时完成子任务，取消父任务完成状态会同时取消子任务完成状态。所有子任务完成时父任务自动完成；新加未完成的子任务会重新打开父任务。
- 子任务可折叠，显示完成数量。已完成父任务归入可折叠的「已完成」区域，可重新勾选恢复。
- 名称在回车或离开编辑框时保存；新增内容保存成功后才清空输入。删除任务时提示其子任务也会删除。
- 保存到这台 Mac 的 `workspace-tasks.json`，与客户端 `state.json` 位于同一目录。按主机和工作区区分，同一工作区的全部终端共用；不随 Agent 状态变化，不同步 CLI 任务，不提供跨设备同步。
- 原先的停止、重试、归档和导出入口移入「会话信息」。

## 文件

- 左侧阅读文件，右侧目录树展开文件夹；始终复用同一个文件标签，点击其他文件时原位切换内容、文件名与路径。再次从「+」选择「打开文件」会返回当前文件。
- 目录树按需读取目录，文件夹优先排序；筛选已展开目录中的文件，保留文件夹以便继续查找。刷新会重读根目录及已展开目录。
- 顶部显示相对路径；文件内容为只读，支持行号、原生文本选择、复制和横纵滚动。本机文件可在默认应用中打开。
- 当前支持 UTF-8 文本，预览上限为 512 KB；二进制及其他编码显示明确说明。每层目录最多显示 5,000 项。
- 根目录取当前会话的实际执行目录，兼容隔离工作区；远程文件通过运行程序读取。符号链接不能跳出当前根目录，特殊设备及管道不读取。

## Git Diff

- 在侧栏内选择文件、阅读统一差异，新增行绿色、删除行红色、区块标记暖色。
- 有会话基准时对比基准提交，否则对比 HEAD；首次提交前也可查看。
- 包含已暂存、未暂存及未跟踪文件。重命名按删除旧路径和新增路径展示；支持中文、空格和换行文件名。
- 只读操作，不暂存、提交或恢复文件。差异超过预览限制时显示截断说明。

## 端口与网页

- 输入端口号（例如 3000、5173）或 HTTP / HTTPS 地址，内嵌网页提供地址栏、刷新、前进、后退、外部浏览器入口和失败重试。
- 远程主机的 localhost / 127.0.0.1 / ::1 地址通过 SSH 转发到本机临时端口；沿用用户 SSH 配置和主机密钥校验。直接 SSH 模式也支持端口转发。
- 关闭标签或退出应用会关闭转发；收起侧栏或切换标签保留网页会话。公网网址从本机访问。
- 不绕过 HTTPS 证书校验。预览页使用非持久化的独立网页数据存储；需要特殊域名、固定 Origin 或自签名证书的服务可能需要在外部浏览器配置后访问。

文件与网页标签在本次应用运行期间按主机、工作区、实际目录与基准保留；重启应用后不恢复标签。会话信息继续显示当前选中会话的执行信息；任务清单独立按主机和工作区保存，切换终端与重启应用均保留。

## 验证

- `python3 tests/panel_integration.py`：实际文件和 Git 仓库，路径边界、UTF-8/二进制、截断、首次提交、会话基准、新增/删除/重命名及只读性。
- `python3 tests/panel_ssh_integration.py`：生产 Swift 模型经隔离的本机 SSH 服务读取文件、转发 HTTP，并验证关闭后释放端口；同时覆盖 URL 校验、标签生命周期及工作区隔离。
- `tests/AshTests/SidePanelTests.swift` 可在带 XCTest 的 Xcode 环境中运行；仅安装 Command Line Tools 时使用上面的独立检查。
- 原生应用手工验收：文件树展开、文本绘制、Git 增删差异、网页加载与后退；文件标签复用由独立检查覆盖。

- `scripts/swift-check.sh ChecklistChecks /tmp/ash-checklist-checks && /tmp/ash-checklist-checks`：两层结构、父子完成状态、编辑排序删除、保存恢复、工作区隔离及损坏文件保护。
