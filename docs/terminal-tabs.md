# 终端标签与快捷键

选中的终端标签右侧显示叉号；各标签预留相同按钮宽度，切换时不会挤动相邻标签。右键菜单也可关闭终端。⌘W 关闭当前终端并保留应用窗口；关闭最后一个终端后返回工作区欢迎页。关闭运行中或排队中的会话时，先请求停止，再归档；直接 SSH 会话关闭客户端连接。文件与托管执行记录保留，停止失败时保留标签并显示错误。关闭单栏当前标签后选择右侧相邻标签，没有右邻时选择左邻；关闭分屏时保留其他面板并恢复输入焦点。

默认 ⌘1–⌘9 选择对应位置的终端，⌥⌘← / ⌥⌘→ 向左 / 右切换，首尾循环。不足对应标签数量时数字快捷键不执行。分屏中切换到已显示的会话会聚焦该面板，否则替换当前面板。

设置仅保留外观、终端字号和三项终端快捷键，不再提供右边栏显示开关或各主机的 Agent 并发数量。

在「设置 → 终端快捷键」统一配置「按编号切换终端」「切换到左侧终端」「切换到右侧终端」。编号组录入修饰键加任意数字 1–9，就会同时应用到 1–9，不再逐个编号配置；默认 ⌘1–⌘9。左右切换各录入一次组合键，Esc 取消。使用 ⌘ 或 ⌃ 搭配按键，可叠加 ⌥、⇧。与其他终端快捷键、已有应用操作及常用系统编辑操作冲突时，在正在编辑的行下提示；「恢复默认」恢复整套终端快捷键。修改立即写入客户端 state.json，菜单同步更新。

旧版第一个数字配置若仍为数字键，则沿用其修饰键作为整组设置；非数字配置恢复默认数字组，冲突的方向配置恢复默认。统一修改数字组、双向冲突检查、冲突时整组保持原值、重启保存和旧配置迁移均由 TerminalTabChecks 验证。实际界面确认仅三项快捷键，录入 ⌥⌘3 后显示并应用 ⌥⌘1–9。

## 自定义标签名称

双击标签或右键选择「重命名…」打开编辑窗口。名称支持中文及 Unicode，自动去除首尾空白，禁止空名称、控制字符和超过 120 个字符的输入。「恢复原名称」把输入框还原到会话原始名称，保存后生效；取消不会修改名称。长名称在标签内截断，悬停可查看全文；会话信息与关闭按钮使用同一显示名称。

名称作为本机显示偏好写入 state.json 的 terminalTitles，按主机 ID 和会话 ID 分开保存。本地与 SSH 终端都可离线重命名，运行程序的刷新不会覆盖显示名称；不修改会话进程、运行程序中的原始任务标题或其他设备的名称。旧客户端状态缺少该字段时沿用原名称；保存失败时恢复原值。
