# 终端标签与快捷键

一个标签页可以包含一个终端，也可以包含多个分屏终端。合并后上方只显示一个组合标签、成员名称和终端数量。切换标签会切换整个页面；返回组合页时恢复分屏、比例及最后聚焦的终端。

选中的标签右侧显示叉号。叉号、右键「关闭标签页」和 ⌘W 关闭该页中的所有终端并保留应用窗口；也可从组合标签的成员子菜单单独关闭一个终端。运行中或排队中的会话先请求停止，再归档；直接 SSH 会话关闭客户端连接。文件与执行记录保留。停止失败时保留失败的会话与尚未处理的成员，并显示错误。关闭最后一个标签后返回工作区欢迎页。

默认 ⌘1–⌘9 按上方标签页的位置选择，组合页计为一个标签；⌥⌘← / ⌥⌘→ 在标签页之间循环切换。不会把独立标签的终端替换进组合页的某一个面板。点击组合页内部的终端只改变该页的焦点。

拖动时显示跟随鼠标的浮动标签和落点提示。拖到另一个标签上默认左右合并，按住 ⌥ 松开则上下合并；拖到终端边缘可选择四个方向。合并时两个标签收拢为一组，目标标签短暂高亮。系统「减少动态效果」开启时取消位移、缩放动画。右键组合页可左右/上下排列、拆为独立标签页，或只移出某个成员。

组合页内的每个终端名称都是独立小标签：点击切换组内焦点，双击重命名。拖动名称到标签栏右侧空白处会拆出为独立标签页，拖到其他标签或终端边缘会移动这个成员。拖动组合页左侧的分屏图标则移动整组。取消拖动或拖到窗口外不会拆组。

所有标签组、各组的布局与焦点保存在本机 state.json 的 terminalGroups；旧的单一分屏布局自动迁移成一个组合页，其余会话各自保留独立标签。运行时协议仍兼容旧版，仅同步当前页的旧布局字段。

设置仅保留外观、终端字号和三项终端快捷键，不再提供右边栏显示开关或各主机的 Agent 并发数量。

在「设置 → 终端快捷键」统一配置「按编号切换终端」「切换到左侧终端」「切换到右侧终端」。编号组录入修饰键加任意数字 1–9，就会同时应用到 1–9，不再逐个编号配置；默认 ⌘1–⌘9。左右切换各录入一次组合键，Esc 取消。使用 ⌘ 或 ⌃ 搭配按键，可叠加 ⌥、⇧。与其他终端快捷键、已有应用操作及常用系统编辑操作冲突时，在正在编辑的行下提示；「恢复默认」恢复整套终端快捷键。修改立即写入客户端 state.json，菜单同步更新。

旧版第一个数字配置若仍为数字键，则沿用其修饰键作为整组设置；非数字配置恢复默认数字组，冲突的方向配置恢复默认。统一修改数字组、双向冲突检查、冲突时整组保持原值、重启保存和旧配置迁移均由 TerminalTabChecks 验证。实际界面确认仅三项快捷键，录入 ⌥⌘3 后显示并应用 ⌥⌘1–9。

## 自定义标签名称

双击独立标签或右键选择「重命名…」打开编辑窗口；组合页从各成员的子菜单分别重命名，组合名称随之更新。名称支持中文及 Unicode，自动去除首尾空白，禁止空名称、控制字符和超过 120 个字符的输入。「恢复原名称」把输入框还原到会话原始名称，保存后生效；取消不会修改名称。长名称在标签内截断，悬停可查看全文。

名称作为本机显示偏好写入 state.json 的 terminalTitles，按主机 ID 和会话 ID 分开保存。本地与 SSH 终端都可离线重命名，运行程序的刷新不会覆盖显示名称；不修改会话进程、运行程序中的原始任务标题或其他设备的名称。旧客户端状态缺少该字段时沿用原名称；保存失败时恢复原值。
