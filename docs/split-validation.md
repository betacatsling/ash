## 2026-09-07 四方向拖放与细分隔线

标签和分隔线由限定在各自可见区域内的原生鼠标处理接管，避免标题栏移动窗口或祖先点击手势抢走事件。命中范围同时取自身 bounds 与 visibleRect 的交集，防止没有裁剪的原生视图拦截相邻标签。保留普通点击、双击重命名、关闭按钮、键盘和右键菜单；Esc、窗口失焦、移出窗口后松开取消拖动。

布局支持左、右、上、下四个落点以及混合嵌套。接缝只占 1pt，与终端使用同一背景；透明的 9pt 拖动区域便于调整比例。终端视图以会话 ID 保持稳定，移动、调整大小、关闭分支不会重启会话。方向和比例保存在本机 state.json；旧服务器仍接收原来的扁平会话顺序。

- `scripts/swift-check.sh TerminalLayoutChecks && .build/TerminalLayoutChecks`：四方向命中与插入、混合布局、替换与聚焦、关闭分支、移动已有终端、比例保存、最小尺寸与旧布局兼容。
- `ModelChecks`、`TerminalTabChecks`：现有左右顺序、快捷键、关闭会话、持久化及真实 runtime 检查。
- `scripts/swift-ui-check.sh`：在独立窗口中，通过 AppKit 鼠标事件验证选中标签拖动、上下/左右/混合落点、窗口位置不变、原终端实例和焦点保留、单击、双击重命名、Esc/外部落点取消、两种方向的分隔线拖动、保存恢复和键盘焦点。仅启动隔离的本地测试进程，不连接个人主机。
- 默认生成离屏预览到 `.build/split-qa`；设置 `ASH_UI_SCREENSHOTS=1` 会捕获测试窗口的实际合成画面，需要系统屏幕录制权限。

## 2026-09-07 实际标题栏拖动的补充修复

上述模拟鼠标事件没有经过 WindowServer，不能单独证明系统标题栏不会移动窗口。实际 Ash 窗口复验发现，隐藏标题栏仍可能在应用收到事件前进入系统拖窗流程。按 [NSWindow.isMovable 的说明](https://developer.apple.com/documentation/appkit/nswindow/ismovable)，主窗口禁用系统发起的拖动；顶部空白区域单独通过应用处理鼠标序列来移动窗口。

标签滚动区与空白拖窗区使用相邻布局，原生命中区域不重叠。拖窗区额外检查命中的原生视图，避免拦截标签和按钮。自动检查增加系统拖窗标志与区域不重叠断言；仍需用实际鼠标操作验收。

实际安装版通过电脑操作工具验证：选中标签拖到另一终端下方形成上下分屏，再拖到右侧恢复左右分屏，两次操作窗口坐标保持不变；拖顶部空白处窗口坐标改变，随后恢复原位。终端会话持续保留。正式构建和应用包校验通过。

## 2026-09-07 分屏组作为标签页

一个标签页现在拥有自己的布局树与焦点。拖放合并后只保留一个组合标签，独立的第三个标签全页显示；再次选择组合页恢复原布局和比例。拖动整个组合标签会移动该组，不能合并进自身。标签之间默认左右合并，按住 ⌥ 则上下合并；终端边缘仍支持四方向落点。

拖动增加非激活浮动预览、源标签淡出、清晰落点提示。合并时浮动标签向目标收拢，标签栏弹性调整宽度，目标短暂高亮；终端本体的尺寸仍不参与动画。减少动态效果时关闭位移和缩放。右键可调整组内方向、拆开整组或移出单个终端。

- `TerminalGroupChecks` 验证整页切换、组布局与比例保留、组合并、移出、拆组、关闭、旧状态迁移及持久化。
- `ModelChecks`、`TerminalLayoutChecks`、`TerminalTabChecks` 和 `AppStoreChecks` 通过。真实隔离运行时检查组合页全部成员的停止归档，以及组内停止失败时保留失败和未处理成员。
- 实际 Ash 窗口验证旧分屏转为一个组合标签、点击独立标签全页切换、返回原组恢复分屏、右键拆开及标签拖到标签进行合并。未关闭个人会话。
- 原生事件检查同步改为按组计数、整页切换和组合并；此轮实际鼠标验收使用电脑操作工具，未用模拟事件替代系统窗口验证。
