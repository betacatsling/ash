# 拖动分屏验证

2026-09-05，初版布局：本地 macOS 独立测试工作区，三个真实 Shell 会话。

- 从顶部标签栏拖入目标终端左侧，得到 C / A / B 三栏。
- 拖动终端标题栏到最右侧，得到 A / B / C，原会话继续运行。
- 拖动 6pt 宽分隔线，确认相邻两栏宽度改变。
- 收起 B 面板后，B 标签仍保留；再拖到右侧，得到 A / C / B，原有输出仍在。
- 点击终端正文能切换当前会话，右侧终端能独立输入。
- 退出测试应用后检查保存数据：顺序为 A / C / B、焦点为 B；运行时仍只有原来的三个运行中会话。
- 独立 Swift 模型检查通过：左右插入、已显示终端移动、点击聚焦、隐藏标签替换、无效落点、过期会话过滤、旧双栏迁移、本地和服务器编码往返。
- `scripts/test.sh` 通过，包括 15 项真实运行时集成检查；新增多栏顺序持久化和重复 ID 拒绝检查。
- `scripts/build.sh debug` 成功；后续整理后开发产物改为 `.build/dev/Ash.app`。

当前范围是同一工作区内的左右多栏布局。保存会话顺序；新增、移除或重排面板时重新均分宽度。重启后宽度恢复均分。
