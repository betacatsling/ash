# Ash 原生界面方向草案

状态：架构阶段的历史草案。实际落地规范以 [设计系统](design-system.md) 为准。

- 推荐方向：工作区优先，紧凑导航 + 终端画布 + 可折叠 Inspector。
- 对比方向：终端优先的极简布局；任务优先的队列布局。
- 字体：界面使用系统 SF Pro，终端默认 SF Mono，保留用户配置入口。
- 图标：SF Symbols；状态使用文字和图标共同表达。
- 基础间距：8 pt；密集控件允许 4 pt 子刻度。
- 色彩方向：温和中性色，暖琥珀强调色候选 #B76A24；明暗主题分别检查对比度后确定最终颜色。
- 中性色候选：浅色背景 #F6F5F2、深色背景 #232321；实际原生控件优先采用系统语义颜色。
- 终端背景：实色，高对比度；装饰不干扰文本与光标。
- 标志性细节：工作区旁的主机标识和任务等待状态，帮助用户立即定位需要处理的上下文。
- 原生行为：菜单、快捷键、焦点、输入法、拖放和辅助功能与视觉共同验收。
- 文案（用户明确偏好）：名称、操作与状态保持简洁；不在界面常驻功能介绍、宣传语或重复引导。空状态优先一句短标题；保留错误原因与操作后果，补充说明按需放入悬停提示。

本阶段不产出最终控件尺寸、窗口效果或设计资产。
